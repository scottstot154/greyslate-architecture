# Architecture Firm Website

This context defines the public-facing language for an architecture firm website that showcases completed and ongoing work, attracts clients, and supports project progress updates.

## Language

**Project**:
A public-facing record of an architecture commission or design engagement, covering both completed portfolio work and ongoing work with progress updates, images, and case-study content.
_Avoid_: Portfolio item, job, work

**Prospective Client**:
A visitor who is evaluating whether to hire the firm, including residential clients, commercial or institutional clients, and developers.
_Avoid_: User, lead, audience

**Project Category**:
The primary public grouping used to sort and browse Projects: Residential, Commercial, Institutional, Interiors, Renovation, or Master Planning.
_Avoid_: Type, sector, service category

**Project Stage**:
A named phase of a Project: Concept, Design Development, Approvals, Construction, or Completed.
_Avoid_: Percentage complete

**Progress Update**:
A dated public note about a Project milestone, with an optional image.
_Avoid_: Status percentage
